# 维尔瑟亚大陆基础设定

## 一、大陆整体格局

维尔瑟亚大陆整体呈现出明显的区域性自然分布。

大陆中央为广阔的**平原与低缓台地**，向北逐渐转变为寒原、冻土与永久雪原；向西逐渐进入干旱荒原、高原与大型山脉；向东则逐渐过渡为丘陵、林地与古老森林；向南地势逐渐降低，最终进入河谷、冲积平原、沿海地区与广阔海洋。

大陆中央同时是各方向交通与文明交流最密集的区域。

---

# 二、中央平原台地

大陆中央由大面积平原、缓坡与低缓台地组成，是维尔瑟亚人口、农业、交通与城市最为集中的地区。

多个主要**人类势力**分布于此。

中央地区也是大陆主要：

* 商路
* 魔导铁路
* 河运线路
* 空艇航线
* 云端列车线路

的交汇区域。

因此中央地区不仅是人类文明核心，也是各族技术、商品与人员交流最频繁的大陆枢纽。

---

# 三、北部雪原

大陆向北气候逐渐寒冷，地貌依次从中央北部平原过渡为：

**寒冷草原 → 针叶林与冻土地带 → 苔原 → 永久雪原与冰川。**

魔族主要聚居区域位于北部寒原与雪原附近。

更北侧的永久冰原环境极端，人口稀少，分布着冰川、雪山、冻结湖泊以及大量寒地魔物，是大陆较危险的自然区域之一。

---

# 四、西部荒原与山脉

大陆西部整体干旱崎岖，从中央地区向西延伸时，地貌大致依次变化为：

- 大型沙漠
- 戈壁与岩石荒原
- 半干旱草原
- 高原与峡谷
- 荒漠盆地
- 巨型山脉

西部东缘首先是一片广阔沙漠，**萨赫拉维亚**位于沙漠边缘，是进入西部地区的重要门户。沙漠内部零散分布着依托绿洲建立的小型城市与聚落，大多各自为政，常住人口以人类和适应沙漠环境的半兽人为主。

继续向西，沙漠逐渐过渡为戈壁、荒原与高原地带，最终进入规模庞大的西部山脉。

西部山脉是**龙族活动最集中的区域**。龙谷位于山脉深处，此外也有大量成年龙族独自占据山峰、峡谷或偏远山地作为自己的领地。

西部同时拥有极为丰富的矿脉，是大陆最重要的矿业区域之一，分布着大量矮人矿井、地下工坊、工程聚落以及规模庞大的**万炉矿渊**。
---

# 五、东部森林

大陆向东降水逐渐增加，植被也越来越茂密。

中央平原首先过渡为丘陵与疏林，之后逐渐进入大型森林，最终形成古老而广阔的**精灵之森**。

整体环境大致呈现：

**农耕平原 → 林地与丘陵 → 普通森林 → 古老魔法森林 → 精灵之森核心区。**

精灵族几乎全部生活在森林最深处。

外围森林同时形成天然缓冲，使精灵族能够长期保持较为封闭的社会状态。

---

# 六、南部沿海与海洋

中央大陆大量河流最终向南流动，并在南方形成：

* 河谷
* 冲积平原
* 湿地
* 三角洲
* 港口地区
* 沿海城市

南部沿岸因此成为大陆重要的农业、贸易和航运区域。

继续向南则进入广阔海洋。

**海族主要生活于南部海洋之中**，部分海族会长期居住在沿海城市，因此南部也是陆地种族与海族交流最为频繁的地区。

---

# 七、云端天境

中央平原高空存在大片稳定的高空气流与魔力环境。

羽族在云层之间建立了由大量浮空岛组成的**云端天境**。

云端天境并非单一岛屿，而是由不同规模的：

* 主岛
* 居住岛
* 农业浮岛
* 魔导设施岛
* 小型自然浮岛

共同组成的大型高空文明区域。

绝大多数羽族居住于此。

从地面仰望时，浮空岛往往被云层遮挡，只有部分巨大岛屿或阴影偶尔能够被地面居民观察到。

---

# 八、地下区域

矮人并没有一个覆盖大片地表的单一聚居区。

大量矮人聚落、矿井、工坊和地下设施分布于整个大陆地下。

主要集中于：

* 西部山脉
* 中央台地
* 北部山地区域
* 东部森林地下

因此大陆实际上存在一层与地表区域相互重叠的**地下活动网络**。

地表政治边界并不一定与地下矮人聚落的分布范围一致。

---

# 九、兽裔分布

兽裔没有统一的核心生态区域。

兽人会根据不同动物原型和生活习性分布于不同自然环境。

例如：

* 北境常见耐寒型兽裔
* 中央平原常见草原与常规陆生型兽裔
* 西部常见适应荒原与山地的兽裔
* 东部森林常见林地型兽裔
* 南部沿海存在少量亲水型兽裔

半兽人则高度城市化，广泛生活于大陆各地的人类及其他种族城市中。

---

# 十、大陆气候轴

维尔瑟亚大陆拥有两条较明显的整体环境变化轴。

## 南北方向

**温暖海洋 → 温和沿海 → 中央平原 → 寒原 → 永久雪原**

纬度越高，气候整体越寒冷。

## 东西方向

**干旱山脉与荒原 → 中央温和平原 → 湿润林地与古森林**

越向西环境越干燥、崎岖；越向东降水与森林覆盖率越高。

这些变化均为渐进式过渡，而非不同生态区域突然截断。

---

# 十一、大陆主要水系

维尔瑟亚拥有多条大陆级大型河流。

主要水源来自：

* 西部山脉
* 北部雪山与融雪区
* 中央高地

大部分大型河流最终穿过中央和南部地区，汇入南方海洋。

这些河流支撑了：

* 农业灌溉
* 城市发展
* 内河航运
* 魔导工业
* 大型贸易路线

也是现代以及古代文明最重要的聚居轴线之一。

具体河流名称与走向将在后续地域设计中确定。

---

# 十二、各族核心地域对应

| 种族 | 主要地理分布         |
| -- | -------------- |
| 人类 | 中央平原与台地，多势力分布  |
| 羽族 | 中央平原上空的云端天境    |
| 海族 | 南部海洋及沿海地区      |
| 魔族 | 北部寒原与雪原附近      |
| 龙族 | 西部山脉与荒原        |

---

# 十三、大陆整体文明结构

维尔瑟亚并不存在完全按种族切割的大陆格局。

除精灵等较为封闭的种族外，各地普遍存在不同程度的跨种族人口流动。

其中中央与南部大型城市的多种族混居程度最高。

整个大陆可以概括为七个主要地理概念：

**北境雪原**——寒原、冻土与魔族主要区域
**西境荒岭**——荒漠、山脉、龙族与矿业地区
**中央台原**——人口、农业、交通与人类文明核心
**东境古森**——森林体系与精灵之森
**南部海疆**——沿海、港口、海洋与海族文明
**云上天境**——羽族浮空岛群
**地下深域**——遍布大陆的矮人地下聚落与矿业网络

---

# 十四、核心地理原则

维尔瑟亚大陆的地域设计遵循以下原则：

1. 不同生态区域之间自然渐变，不采用生硬分割。
2. 中央平原是大陆交通、贸易和文明交流核心。
3. 越远离中央，各地区种族与环境特色越明显。
4. 大型文明通常沿河流、海岸、矿区和重要交通路线发展。
5. 种族聚居地代表核心分布区，而非严格禁止其他种族进入。
6. 地表、天空、海洋和地下共同构成大陆完整的文明空间。
7. 后续国家、城市与大型地点设计必须与所在区域的气候、地形、资源和交通逻辑保持一致。

## 核心设定

**中央连接整个大陆，而四方塑造不同文明。玩家从中央向任何方向旅行，都会逐渐进入截然不同的自然环境与种族文化区域。**
