# 声望与羁绊系统规则

# 一、声望系统

**声望值范围：-100 ～ 100**

声望代表社会对玩家的整体评价，会影响NPC初次见面时的态度、信任程度以及部分服务与任务。

## 声望等级

| 数值 | 等级 |
|---|---|
| -100 ～ -81 | 公敌 |
| -80 ～ -51 | 恶名昭著 |
| -50 ～ -21 | 不受欢迎 |
| -20 ～ 20 | 中立 |
| 21 ～ 50 | 声名良好 |
| 51 ～ 80 | 受人敬重 |
| 81 ～ 100 | 威望卓著 |

## 声望变化

声望根据玩家产生**公开社会影响**的行为动态变化，例如：

- 完成公开任务；
- 救助当地居民；
- 为某个组织作出贡献；
- 解决重大危机；
- 犯罪、欺诈或袭击居民；
- 破坏当地利益；
- 与某势力公开敌对。

秘密行为在没有被发现或传播之前，**不会自动影响声望**。

重复完成影响很小的行为不能无限刷取声望。

## 声望影响

较高声望可能带来：

- 更友好的初始态度；
- 更容易获得信任；
- 特殊任务或合作机会；
- 部分商业或社会便利；
- 更高的社会认可度。

负面声望可能带来：

- 警惕；
- 拒绝服务；
- 更严格的检查；
- 敌意；
- 通缉或其他合理后果。

**声望不是强制控制。**

即使玩家拥有极高声望，NPC仍然可以根据自身人格、利益与立场拒绝玩家。

---

# 二、羁绊系统

**好感度范围：-100 ～ 100**

羁绊表示某个重要NPC对玩家个人的态度和关系程度。

## 好感等级

| 数值 | 关系 |
|---|---|
| -100 ～ -81 | 死敌 |
| -80 ～ -51 | 仇恨 |
| -50 ～ -21 | 厌恶 |
| -20 ～ 20 | 普通 / 陌生 |
| 21 ～ 50 | 友好 |
| 51 ～ 80 | 亲近 |
| 81 ～ 100 | 深厚羁绊 |

**深厚羁绊不等于爱情。**

实际关系可以是朋友、恋人、家人般关系、师生、伙伴或其他形式，应根据真实互动决定。

---

# 三、羁绊列表

GM只在有必要时将NPC加入玩家的**羁绊列表**。

通常满足以下情况之一时才应加入：

- NPC本身属于重要角色；
- 玩家与其发生了具有持续意义的互动；
- 双方建立了值得长期记录的关系；
- NPC之后仍可能频繁出现在玩家生活中。

普通路人、临时店员、只见过一次的冒险者等角色，不应随意加入羁绊列表。

如果普通NPC后来与玩家建立了长期关系，可以在那时加入。

---

# 四、好感度变化

好感度根据NPC自身人格以及玩家的实际行为动态变化。

可能提高好感的行为包括：

- 提供真正有价值的帮助；
- 尊重对方；
- 长期相处；
- 履行承诺；
- 在关键时刻支持对方；
- 做出符合NPC价值观的行为。

可能降低好感的行为包括：

- 欺骗；
- 背叛；
- 持续冒犯；
- 伤害对方或其重视的人；
- 违背重要承诺；
- 做出严重违反其价值观的事情。

具体变化幅度由GM根据事件的重要程度动态决定。

普通聊天、反复送出廉价物品等低价值行为不能无限刷取好感度。

---

# 五、好感度影响

好感度会影响NPC：

- 对玩家的语气与态度；
- 是否愿意花时间帮助玩家；
- 是否愿意分享私人信息；
- 是否愿意同行或合作；
- 对玩家错误行为的容忍程度；
- 是否愿意建立更深入的关系。

但好感度不能迫使NPC违背人格与原则。

即使好感度很高，NPC也可以：

- 拒绝不合理请求；
- 与玩家发生争执；
- 对玩家某些行为感到失望；
- 因自身职责暂时站在玩家对立面。

---

# 六、声望与羁绊的区别

**声望 = 群体如何看待玩家。**

**羁绊 = 某个具体NPC如何看待玩家。**

二者彼此独立。

玩家可能在某势力拥有极高声望，却被其中某名NPC讨厌。

也可能在某地区声名狼藉，却与其中某个人保持深厚友谊。

NPC对玩家的最终态度，应综合考虑：

**个人羁绊 ＞ NPC自身人格与利益 ＞ 玩家相关声望 ＞ 其他情境因素**

---

# 七、提示与面板

声望和羁绊发生明显变化时，在正文下方提示区显示，例如：

**【南海自由联邦声望】18 → 25｜中立 → 声名良好**

**【莉莉娅·诺克维尔 好感度】47 → 53｜友好 → 亲近**

微小且没有实际意义的变化可以不频繁提示。

---

# 八、核心原则

**声望记录玩家与社会的关系，羁绊记录玩家与重要NPC的关系。**

**任何数值变化都必须来源于实际发生的事情。**

**高数值代表更有利的关系，不代表玩家能够控制NPC。**
