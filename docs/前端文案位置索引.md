# 前端文案位置索引

本文按页面列出玩家在界面上看到的文字写在哪个文件、大约第几行，方便直接修改。

- 前端路径都相对于 `apps/web/src/`，后端路径相对于 `apps/api/`。
- 行号是整理时（2026-10-15）的位置，改动后会漂移；找不到时，用文案原文在文件里搜索最快。
- 文案大多直接写在组件的 JSX 里（`<h2>…</h2>`、`placeholder="…"`、`aria-label="…"` 等）。`aria-label` 是读屏软件朗读的文字，屏幕上看不到，但也是给玩家的文案。

## 修改后怎么生效

| 改的位置 | 需要做什么 |
| --- | --- |
| `apps/web/src/**` | 在 `apps/web` 下运行 `npm run build` 重新构建（游戏读取的是 `apps/web/dist`），然后刷新页面；开发时用 `npm run dev` 可即时预览 |
| `apps/api/catalog.py` | 重启游戏服务（关闭服务窗口后重新运行 `启动游戏.bat`）。已经创建的存档可能保存了当时的世界资料副本，新文案主要在新建角色时看到 |

字段与页面上区块的对应关系：

- **种族**（`steps/RaceStep.tsx`）：
  - `tagline` 是标题下的一句话，`description` 是正文第一段，`lifespan_text` 是“寿命”。
  - `facts` 是寿命旁边的几格小资料。
  - 下面几个区块依次对应：`magic_affinity` 天赋与魔力，`combat_style` 战斗方式，`technology` 文明与技术，`society` 和 `distribution` 社会与分布，`representatives` 代表人物，`creation_notes` 创建提示。
- **地区**（`steps/LocationStep.tsx`）：
  - `tagline` 是副标题，`region` 是所在区域，`environment` 是环境，`description` 是正文。
  - 下面几个区块依次对应：`structure` 区域结构，`highlights` 特色（列表），`transport` 和 `access_note` 交通与访问，`arrival_point` 和 `safeguards` 特殊说明。
- **势力**（`steps/FactionStep.tsx`）：
  - `tagline` 是副标题，`description` 是正文。
  - 下面几个区块依次对应：`ideology` 和 `organization` 定位、理念与组织，`headquarters` 总部，`tasks` 任务与委托，`services` 可使用服务，`activities` 可参与活动，`rewards` 奖励与资源，`audience` 和 `access_note` 公开对象与前置。

`catalog.py:707` 的 `NARRATION` 和 `:726` 的 `faction_notice` 目前前端没有读取；设置页的叙事选项和势力步骤顶部提示写在前端（见下文），改这两处才会生效。

## 同一句话出现在多处的情况

改其中一处时，记得同时改其他几处：

- **“当前 AI 无法一次读取这么多故事内容……”**：`playerCopy.ts:11`、`features/game/helpers.ts:228`、`features/game/GameWorkspace.tsx:34`、`features/game/useGameWorkspace.ts:49`。
- **“请先打开设置，在‘生图模型配置’中填写 OpenAI 服务地址和密钥”**：`playerCopy.ts:29`、`features/game/useGameWorkspace.ts:284`。
- **资源名“生命 / 魔力 / 精神 / 精力”**：三处写法各不相同。
  - 角色页带英文缩写，在 `features/game/panels/CharacterPanel.tsx:7`。
  - 剧情页标题区只写中文，在 `features/game/panels/StoryVitals.tsx:5`。
  - 候选卡片在 `features/character/candidate/CandidatePanel.tsx:19`。
- **大联合学院入学试炼的名称**：地区资料写“资质试炼”（`catalog.py` 大联合学院地区条目），势力资料写“天赋试炼”（势力条目的 `access_note`）。
